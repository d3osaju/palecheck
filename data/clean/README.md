# CP-AnemiC, cleaned manifests

Derived from **CP-AnemiC** (Appiahene P., Chaturvedi K., Asare J.W., Donkoh E.T., Prasad M., 2023;
Mendeley Data, DOI [10.17632/m53vz6b7fx.1](https://data.mendeley.com/datasets/m53vz6b7fx/1)), licensed
**CC BY 4.0**. Changes: none to the data; these files only list which images PaleCheck kept and why.
Generated by `model/train.py` (protocol v3).

| File | Rows | Contents |
|---|---|---|
| `cp-anemic-reliable.csv` | 139 | Images whose photograph appears under this record only, with the record and PaleCheck's split (`development`, `lockbox`, `demo`). |
| `cp-anemic-unreliable-groups.csv` | 571 | Images grouped (169 groups) with every other record that shares their photograph: pixel-identical copies, re-encoded copies, re-cropped and mirrored cut-outs. `identical_copies_of_this_image` counts byte-identical copies. |

The 710 records contain 308 distinct photographs. Every group lists different patients (hospital, age, sex or
haemoglobin), so no record in a group can be verified; PaleCheck excludes them all. Detection rules are in
`model/near_duplicates.py` and the Science page.

# CP-AnemiC, cleaned manifests

Derived from **CP-AnemiC** (Appiahene P., Chaturvedi K., Asare J.W., Donkoh E.T., Prasad M., 2023;
Mendeley Data, DOI [10.17632/m53vz6b7fx.1](https://data.mendeley.com/datasets/m53vz6b7fx/1)), licensed
**CC BY 4.0**. Changes: none to the data; these files only list which images PaleCheck kept and why.
Generated by `model/train.py` (protocol v2).

| File | Rows | Contents |
|---|---|---|
| `cp-anemic-reliable.csv` | 386 | Images that are not a copy of any other record's photo, with the record and PaleCheck's split (`development`, `lockbox`, `demo`). |
| `cp-anemic-unreliable-groups.csv` | 324 | Images grouped with every other record that shares their photo: 312 pixel-identical copies (87 groups) plus 12 re-cropped / re-encoded near-identical copies. Includes each record's values and the pixel MD5. |

Every group lists different patients (hospital, age, sex or haemoglobin), so no single record in a group can
be verified; PaleCheck excludes them all. Near-identical rule: 64-bit difference hash within 6 bits, aspect ratio
within 5%, and mean absolute pixel difference ≤ 6 (0–255) on a 128×64 grid after flattening onto white
(`model/near_duplicates.py`).

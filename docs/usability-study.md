# Usability study (5–8 classmates, ~10 minutes each)

Judges score *Impact* higher when real people have used the thing. This study tests whether people can **use**
PaleCheck, not whether it is medically accurate: it needs no blood tests and no health data.

## Setup

- Each participant uses their own phone and opens https://palecheck.zetalabs.in (or scans the card's QR).
- Use the **research samples** and a **red sticker** with the card, not anyone's eyelid, so no health data is collected.
- Don't help unless they're stuck for more than 60 seconds. Note where they get stuck.

## Tasks (time each one)

1. Open the app and find out what PaleCheck does. *(Can they explain it in one sentence?)*
2. Run a check on research sample #2 and tell me the result. *(Do they understand "overlap zone"?)*
3. Photograph the red sticker next to the card, select it and measure it.
4. Switch the language to Malayalam or Hindi.
5. Find out how accurate the app is. *(Do they find the honest-accuracy box or the Science page?)*

## Afterwards: System Usability Scale (SUS)

Rate 1 (strongly disagree) to 5 (strongly agree):

1. I would like to use this app regularly.
2. I found the app unnecessarily complex.
3. I thought the app was easy to use.
4. I would need help from someone technical to use this app.
5. The parts of the app worked well together.
6. There was too much inconsistency in this app.
7. Most people would learn to use this app very quickly.
8. The app was very awkward to use.
9. I felt confident using the app.
10. I needed to learn a lot before I could get going with this app.

**Score:** for odd items, score − 1; for even items, 5 − score. Add them up and multiply by 2.5 (0–100).
Above 68 is above average; above 80 is excellent.

Also ask: *"After using it, would you get a blood test if it said 'paler than usual'?"* (yes / no / maybe)
